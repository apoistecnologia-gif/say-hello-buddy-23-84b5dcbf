# Secret Name Checklist

## Automatically Provided (DO NOT CONFIGURE MANUALLY)
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `SUPABASE_ANON_KEY`
- `SUPABASE_DB_URL`

## Manually Required (SUPABASE SECRETS)
- `GOOGLE_MAPS_PLATFORM_API_KEY` (or `GOOGLE_MAPS_API_KEY`)
- `MERCADOPAGO_ACCESS_TOKEN`
- `MERCADOPAGO_WEBHOOK_SECRET`
- `FIREBASE_SERVICE_ACCOUNT_B64` (Base64 of the Service Account JSON)

## External Provider Credentials (FOR THIRD-PARTY UI)
- `GOOGLE_CLIENT_ID` (For Google OAuth)
- `GOOGLE_CLIENT_SECRET` (For Google OAuth)

## Test Secrets
- `TEST_USER_EMAIL`
- `TEST_USER_PASSWORD`
