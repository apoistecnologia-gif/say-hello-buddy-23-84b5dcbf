# Northeast address search candidate (inactive)
Separate offline SQLite FTS5 benchmark on a disposable runner. Verified source hash is identical to approved Valhalla graph. Uses tagged OSM address nodes and named place nodes only. Accent-insensitive, token-literal prefix search, bounded inputs and result count. No geocoding of arbitrary house numbers, streets without address nodes, way/building polygons, interpolation, reliable municipal attribution or reverse geocoding. Place smoke checks are near reference public city centers; coarse bounding rectangle is a resource filter, never permission to request rides. No production, no DB migrations, no upload of index/addresses, no GPS or passenger data, no app wiring. Reports aggregate counts and geographic test results only. Source latest URL is mutable: stop on hash mismatch. The old 1,000-point in-app catalog cannot ingest this index; an authenticated, paginated server contract and geographic authorization must be reviewed independently.
