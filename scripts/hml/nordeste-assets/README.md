# Offline Northeast asset builder compatibility gate
Reuses the exact prior validated schema, style, archive verifier and address importer. Builds a toolbox from official Ubuntu 24.04 base resolved to a digest on the hosted runner; records package versions and verifies the pinned Planetiler JAR. Runtime has arbitrary nonroot UID, no network, read-only root/source and limited resources. Output only to separate writable assets directory; compares baseline addressed tile and address counts, validates and hashes candidate. No publication, credentials, production, activation or cluster changes. The hosted test source URL is mutable and must match the exact approved hash. After success, pin the recorded base digest and review the toolchain for the separate HML OpenShift binary build; apt repositories are mutable, so a distinct image build must be validated independently.
